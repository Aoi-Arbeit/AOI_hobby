## 1. プロジェクト概要

### 1.1 目的

ブラウザ上で報告書・企画書などのビジネス文書を作成し、デバイスや環境に依存しない一貫したレイアウトで PDF（A4サイズ）として出力できる Web アプリケーションを構築する。

### 1.2 背景・課題

- 既存の Word / Google ドキュメントではブラウザ印刷時にフォント・余白がデバイスによってずれる。
- ピクセル単位の絶対座標管理により、どのデバイスでも同一の印刷結果を保証したい。
- 外部サーバー不要で動作する軽量な Vanilla JS ベースの実装が求められる。

### 1.3 スコープ

| 区分 | 内容 |
|------|------|
| 対象 | 報告書・企画書テンプレートの作成・編集・PDF 出力 |
| 対象外 | ユーザー認証、クラウド保存、データベース連携（初回リリース） |

## 2. 機能要件

### 2.1 書類作成機能

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-01 | テンプレート選択 | 報告書・企画書テンプレートを選択して編集開始 | 必須 |
| F-02 | テキスト入力 | タイトル・本文・箇条書きなどの入力フィールド | 必須 |
| F-03 | 画像挿入 | ローカル画像をドラッグ＆ドロップまたはファイル選択で挿入 | 重要 |
| F-04 | 表作成 | 行・列を指定してセル入力できるテーブルコンポーネント | 重要 |
| F-05 | ページ管理 | ページの追加・削除・並べ替え（最大 20 ページ） | 重要 |
| F-06 | リアルタイムプレビュー | A4 サイズのプレビューをブラウザ上でリアルタイム表示 | 必須 |
| F-07 | フォント選択 | ゴシック体・明朝体などフォントファミリーを指定可能 | 通常 |
| F-08 | カラー設定 | テキスト色・背景色のカラーピッカー対応 | 通常 |

### 2.2 PDF 出力機能

PDF 出力はブラウザの印刷機能（`window.print()`）ではなく、**jsPDF** または **html2canvas + jsPDF** を用いてクライアントサイドで生成する。これにより、プリンタードライバーや OS の設定に影響されない確定的な出力を実現する。

| ID | 要件 | 詳細 |
|----|------|------|
| P-01 | ページサイズ | A4（210mm × 297mm）固定。B5・Letter は将来対応 |
| P-02 | 解像度 | 96dpi 基準のピクセル座標を mm 換算して PDF に埋め込み |
| P-03 | フォント埋め込み | Noto Sans JP / Noto Serif JP を Base64 埋め込みで文字化けを防止 |
| P-04 | ファイル名 | 「テンプレート種別_YYYYMMDD_HHmm.pdf」形式で自動命名 |
| P-05 | メタデータ | タイトル・作成者・作成日を PDF メタデータに書き込み |
| P-06 | 出力確認 | 生成後にブラウザの新規タブでプレビュー表示してからダウンロード |

## 3. 絶対座標管理とレイアウト設計

### 3.1 座標系の定義

すべての要素は A4 用紙を基準とした**論理座標（単位: mm）**で定義する。ブラウザの dpr（デバイスピクセル比）やウィンドウ幅に左右されないよう、レンダリング時に「mm → px」変換を一元管理するユーティリティ関数を設ける。

```js
const DPI = 96;
const MM_PER_INCH = 25.4;
const mmToPx = (mm) => mm / MM_PER_INCH * DPI;

// A4 = 210mm × 297mm → 794px × 1123px (96dpi)
const A4_W_PX = mmToPx(210);  // ≈ 794px
const A4_H_PX = mmToPx(297);  // ≈ 1123px
```

### 3.2 要素の座標管理

各テキストブロック・画像・表などの UI 要素は `position: absolute` で A4 コンテナ内に配置し、`top / left / width / height` をすべて mm 単位のデータとして保持する。プレビュー表示と PDF 出力で同一の座標データを使い回すことで、WYSIWYG（What You See Is What You Get）を実現する。

| プロパティ | 型 | 単位 | 説明 |
|-----------|-----|------|------|
| `x` | number | mm | 用紙左端からの水平距離 |
| `y` | number | mm | 用紙上端からの垂直距離 |
| `width` | number | mm | 要素の幅 |
| `height` | number | mm | 要素の高さ（テキストは自動計算） |
| `fontSize` | number | pt | フォントサイズ（ポイント単位） |
| `fontFamily` | string | — | `'sans'` または `'serif'` |
| `type` | string | — | `'text'` \| `'image'` \| `'table'` \| `'line'` |

#### 要素データの JSON 例

```json
{
  "id": "title-01",
  "type": "text",
  "x": 20,
  "y": 15,
  "width": 170,
  "height": 12,
  "fontSize": 18,
  "fontFamily": "sans",
  "fontWeight": "bold",
  "color": "#1a3a5c",
  "content": "2026年度 第1四半期 業務報告書"
}
```

### 3.3 デバイス間差異の排除方針

- プレビュー用コンテナは常に `A4_W_PX × A4_H_PX` の固定サイズで描画し、`CSS transform: scale()` でビューポートに収める。
- フォントは Web フォント（Google Fonts / Self-hosted）で統一し、システムフォントに依存しない。
- 行高・文字間隔は mm または pt 単位で指定し、相対単位（`em` / `rem`）を使用しない。
- PDF 生成ライブラリには座標を mm 単位で直接渡し、ブラウザのレンダリングを経由しない経路も確保する。

```css
/* A4 キャンバスの固定サイズ定義 */
.a4-canvas {
  position: relative;
  width: 794px;   /* mmToPx(210) */
  height: 1123px; /* mmToPx(297) */
  background: #fff;
  box-shadow: 0 2px 12px rgba(0,0,0,0.15);
  overflow: hidden;
}

/* ビューポートに合わせてスケール */
.a4-wrapper {
  transform-origin: top center;
  transform: scale(var(--canvas-scale));
}
```

## 4. 非機能要件

| カテゴリ | 要件 | 目標値・条件 |
|---------|------|------------|
| パフォーマンス | PDF 生成時間 | 5 ページ以内のドキュメントで 5 秒以内 |
| パフォーマンス | プレビュー描画 | 操作から 100ms 以内に反映 |
| 互換性 | 対応ブラウザ | Chrome 110+, Firefox 110+, Edge 110+, Safari 16+ |
| 互換性 | デバイス | デスクトップ優先、タブレット（iPad）でも閲覧可 |
| 可用性 | オフライン | 一度読み込めばネットワーク不要で動作（PWA 対応推奨） |
| セキュリティ | データ保存 | 入力データは `localStorage` のみ。外部送信なし |
| アクセシビリティ | WCAG | WCAG 2.1 AA レベル準拠（コントラスト比・キーボード操作） |
| 保守性 | コード品質 | JSDoc コメント必須、単体テスト（Jest）カバレッジ 70% 以上 |

## 5. システム構成・技術選定

### 5.1 技術スタック

| レイヤー | ライブラリ / 仕様 | 選定理由 |
|--------|----------------|---------|
| フロントエンド | Vanilla JS (ES2022+) | フレームワーク依存なし。長期保守性と軽量性を重視 |
| モジュール管理 | ES Modules (import/export) | 外部バンドラー不要でブラウザネイティブに動作 |
| PDF 生成 | jsPDF v2 + jsPDF-AutoTable | クライアントサイド PDF 生成。mm 単位指定対応 |
| フォント | Noto Sans/Serif JP (Base64) | 日本語対応、ライセンスフリー、埋め込み可 |
| 画像処理 | html2canvas（補助用途） | Canvas 要素の PDF 変換に使用（テキストは直接描画優先） |
| スタイル | Plain CSS (CSS Variables) | A4 サイズ固定レイアウトに CSS Grid を活用 |
| テスト | Jest + Testing Library | ユーティリティ関数・座標変換ロジックの単体テスト |
| ビルド | Vite（オプション） | 開発時の HMR とバンドル最適化（本番のみ使用） |

### 5.2 ディレクトリ構成（案）

```
project/
├── index.html               # エントリーポイント
├── css/
│   ├── base.css             # リセット・基本スタイル
│   ├── a4-canvas.css        # A4 キャンバス（固定サイズ）
│   └── toolbar.css          # ツールバー UI
├── js/
│   ├── main.js              # アプリ初期化
│   ├── editor.js            # 要素の追加・移動・選択
│   ├── layout.js            # 絶対座標管理・mm↔px 変換
│   ├── pdfExport.js         # jsPDF ラッパー・PDF 出力
│   ├── templates/           # 報告書・企画書テンプレート定義
│   │   ├── report.json
│   │   └── proposal.json
│   └── utils/               # 汎用ユーティリティ
│       ├── coords.js        # mm↔px 変換
│       └── storage.js       # localStorage 操作
├── fonts/                   # Noto CJK フォント Base64
└── assets/                  # アイコン・サンプル画像
```

## 6. UI / UX 要件

### 6.1 画面構成

| 画面名 | 主な機能 |
|--------|---------|
| ホーム画面 | テンプレート一覧（報告書・企画書）の選択。新規作成・既存ファイル読み込みボタン |
| エディタ画面 | A4 プレビュー（中央）＋ ツールバー（上部）＋ プロパティパネル（右側） |
| PDF 出力ダイアログ | ファイル名入力、ページ範囲指定、出力ボタン。生成後に新規タブでプレビュー |

### 6.2 エディタ操作仕様

- 要素のドラッグ＆ドロップによる位置変更（マウス・タッチ対応）
- ハンドルによるリサイズ（最小サイズ制限あり）
- キーボードショートカット：`Ctrl+Z`（元に戻す）、`Ctrl+S`（保存）、`Ctrl+P`（PDF 出力）
- スナップ機能：グリッド 5mm 単位へのスナップ切り替え
- 選択中の要素を `Delete` キーで削除

## 7. テンプレート仕様

| テンプレート | ページ数 | 初期配置要素 | 特記事項 |
|------------|---------|------------|---------|
| 報告書 | 2〜20 | タイトル・日付・作成者・本文・まとめ | 表・グラフ挿入スペースあり |
| 企画書 | 4〜20 | 表紙・目次・課題・解決策・スケジュール | カバーページにロゴ配置可能 |

各テンプレートは JSON 形式で定義し、`elements` 配列に各要素の絶対座標・スタイル情報を記述する。テンプレートファイルは `js/templates/` ディレクトリに配置し、動的に読み込む。

## 9. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| 日本語フォントの埋め込みによる PDF ファイルサイズ肥大化 | 中 | サブセット化（使用文字のみ埋め込み）でサイズを削減 |
| ブラウザによる html2canvas のレンダリング差異 | 中 | テキスト要素は直接 jsPDF で描画し html2canvas に依存しない |
| 大量ページ数での PDF 生成パフォーマンス低下 | 低 | Web Worker で非同期生成、プログレスバー表示 |
| モバイルデバイスでの操作性 | 低 | 初回リリースはデスクトップ優先、タッチ対応は第二フェーズ |
