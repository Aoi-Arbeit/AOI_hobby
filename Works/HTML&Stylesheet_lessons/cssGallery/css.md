# CSS

## font-size

### 指定できる値

| キーワード | 説明 |
| --- | --- |
| xx-small | 最極小 |
| x-small | 極小 |
| small | 小 |
| medium | 中 |
| large | 大 |
| x-large | 極大 |
| xx-large | 最極大 |
| smaller | 一回り小さく |
| larger | 一回り大きく |

### 数値で利用できる単位

| 単位 | 説明 |
| --- | --- |
| px | ピクセル |
| cm | センチメートル |
| mm | ミリメートル |
| in | インチ(1in=約2.54cm) |
| pt | ポイント |
| pc | パイカ(12pt) |
| em | 1em=現在のフォントサイズ |
| ex | 1ex=現在のフォントの小文字"x"の高さ |
