# めんだこRPG 要件定義書

**バージョン**: 1.0
**作成日**: 2026-03-22
**プロジェクト名**: めんだこRPG ～深海の冒険～

---

## 1. プロジェクト概要

### 1.1 ゲーム概要

深海に住む愛らしいめんだこ「メンタ」が、闇の力に支配された深海世界を救う旅に出るターン制RPG。ドラゴンクエストに代表されるコマンド選択式バトルを踏襲し、ブラウザ上で気軽に遊べるミニRPG。

### 1.2 世界観・設定

| 項目 | 内容 |
|------|------|
| 舞台 | 深海王国「アビサル」 |
| 時代 | 海中文明が発展した幻想世界 |
| 雰囲気 | かわいらしい×ちょっとシリアスなダーク深海ファンタジー |
| テーマ | 小さな勇者が大きな勇気で世界を救う |

### 1.3 主人公設定

| 項目 | 内容 |
|------|------|
| 名前 | メンタ（プレイヤーが変更可能） |
| 種族 | めんだこ（深海に住む耳のようなヒレを持つタコ） |
| 性格 | 臆病だがお人よし。困っている人を見ると放っておけない |
| 特技 | 「耳ヒレ」で水流を操る魔法、スミを使ったトリック技 |
| 初期装備 | 小さなランタン（武器）、磯の欠片（防具） |

### 1.4 ストーリー概要

深海王国アビサルは、謎の暗黒生物「ヴォイドクラーケン」の呪いによって光を失い、魚たちが次々と石化し始めていた。めんだこのメンタは、深海の賢者から「光の珊瑚」を集めれば世界を救えると告げられ、3つのダンジョンを巡る旅に出る。

## 2. 機能要件

### 2.1 ゲームフロー

```
タイトル画面
    ↓
ニューゲーム / データロード
    ↓
名前入力（主人公の名前）
    ↓
オープニングムービー（テキスト演出）
    ↓
フィールド探索
    ↓（ランダムエンカウント or イベント）
バトル
    ↓（クリア）
ダンジョンボス戦 → ストーリー進行
    ↓（3ダンジョンクリア）
ラストボス戦
    ↓
エンディング
```

### 2.2 タイトル画面

- ゲームタイトル表示
- 「はじめから」「つづきから」「せってい」のメニュー
- BGM再生（ループ）

### 2.3 名前入力

- 主人公名の変更（デフォルト: メンタ）
- 最大6文字まで入力可能
- ひらがな・カタカナ・漢字・アルファベット対応

### 2.4 フィールド・ダンジョン探索

| 機能 | 詳細 |
|------|------|
| マップ表示 | タイル式マップ（上から見た俯瞰視点） |
| 移動 | キーボード（WASDまたは矢印キー）またはクリック |
| エンカウント | ダンジョン内でランダムエンカウント（歩数ベース） |
| NPC | 村人・商人・賢者などのNPCが存在し、話しかけると会話 |
| 宝箱 | フィールド上に宝箱を配置（アイテム・装備を入手） |
| セーブポイント | 特定の場所（神殿・村）でセーブ可能 |

**エリア構成（全5エリア）**

1. **出発の村「タコ村」** ── 初期拠点。ショップ・宿屋あり
2. **第1ダンジョン「煙突岩の洞窟」** ── 熱水噴出孔エリア。ボス:ホットクラブ
3. **第2ダンジョン「幽霊船の残骸」** ── 沈没船エリア。ボス:シャドウアンコウ
4. **第3ダンジョン「深淵の塔」** ── 最深部エリア。ボス:フロストジェリー
5. **ラストエリア「虚無の深淵」** ── ラスボス:ヴォイドクラーケン

### 2.5 バトルシステム

#### 2.5.1 基本仕様

| 項目 | 内容 |
|------|------|
| 形式 | 1対1（またはめんだこ vs 複数敵） |
| 視点 | サイドビュー（主人公左・敵右） |
| ターン制 | 速さパラメータで行動順を決定 |
| エンカウント | ランダムエンカウント（フィールドシンボルエンカウントも可） |

#### 2.5.2 コマンド一覧

| コマンド | 内容 |
|--------|------|
| たたかう | 通常攻撃。攻撃力に基づきダメージを与える |
| スキル | MPを消費する特殊技（後述） |
| どうぐ | アイテムを使用（回復薬・エーテルなど） |
| にげる | 逃走（成功率あり。ボス戦は逃走不可） |

#### 2.5.3 めんだこのスキル一覧

| スキル名 | MP消費 | 効果 | 習得Lv |
|--------|--------|------|-------|
| スミアタック | 4 | 敵1体にダメージ＋命中率ダウン | 初期習得 |
| ヒレ波動 | 6 | 敵全体に水属性ダメージ | Lv5 |
| 深海の加護 | 8 | HP回復（中量） | Lv8 |
| タコシュート | 12 | 敵1体に強力なダメージ | Lv12 |
| 光の珊瑚術 | 20 | 全体攻撃＋デバフ解除 | ストーリー習得 |
| 深淵の怒り | 30 | 最大ダメージ（ラスボス戦専用解放） | 最終盤 |

### 2.6 パラメータ設計

#### 2.6.1 主人公ステータス

| パラメータ | 略称 | 説明 |
|---------|------|------|
| 最大HP | MHP | 戦闘不能になるHP上限 |
| 最大MP | MMP | スキル使用に必要なMP上限 |
| 攻撃力 | ATK | 通常攻撃のダメージ量 |
| 防御力 | DEF | 受けるダメージを軽減 |
| 素早さ | SPD | ターン順決定・逃走成功率に影響 |
| 幸運 | LCK | クリティカル率・逃走成功率・ドロップ率に影響 |

#### 2.6.2 レベルアップ仕様

- レベル上限: **30**
- 経験値取得: 敵を倒すたびに取得
- レベルアップ時: 全パラメータが上昇、HPとMPが全回復
- Lv5/8/12/20でスキルを習得

### 2.7 装備システム

| 装備箇所 | 種類例 |
|---------|------|
| 武器 | ランタン、光の杖、珊瑚の槍 など |
| 防具 | 磯の欠片、深海の鱗、光の甲殻 など |
| アクセサリ | 貝がらペンダント、深海の涙 など |

- 装備変更によりATK/DEF/SPD等が変化
- 装備には属性（水・光・闇）を設定

### 2.8 アイテムシステム

| アイテム名 | 効果 |
|---------|------|
| 深海のしずく | HP 50回復 |
| 深海のしずく+ | HP 150回復 |
| MPの泡 | MP 20回復 |
| 蘇生の珊瑚 | 戦闘不能から復活（HP25%で回復） |
| 煙幕の墨 | 戦闘から確実に逃げられる（ボス無効） |

- アイテムはショップで購入・宝箱から入手・敵からドロップ
- 所持上限: 各アイテム最大9個

### 2.9 ショップ・宿屋

| 施設 | 機能 |
|------|------|
| ショップ | 武器・防具・アイテムの売買。「買う」「売る」メニュー |
| 宿屋 | ゴールドを支払ってHP/MPを全回復。セーブも可能 |

### 2.10 セーブ・ロード

- **セーブスロット**: 3スロット
- **セーブ方法**: セーブポイント（神殿・宿屋）で手動セーブ
- **保存先**: ブラウザのLocalStorage
- **オートセーブ**: 各ダンジョンボス撃破時に自動保存

### 2.11 ゲームオーバー

- HPが0になると「めんだこはたおれてしまった…」メッセージ
- 「タイトルに戻る」または「最後のセーブに戻る」を選択
- ゲームオーバー画面には哀愁漂うめんだこのイラスト

## 3. 非機能要件

### 3.1 プラットフォーム・技術要件

| 項目 | 要件 |
|------|------|
| 動作環境 | Chrome / Firefox / Edge / Safari（最新版） |
| 実装技術 | HTML5 / CSS3 / JavaScript（Vanilla JS or Phaser.js） |
| 解像度 | 基本800×600px。レスポンシブ対応（スマホは640×480） |
| ファイル構成 | 単一HTMLファイルで動作可能（または最小構成） |
| 外部依存 | なし（ライブラリは任意。CDNでの読み込み可） |

### 3.2 パフォーマンス要件

- 初回読み込みは5秒以内（通常回線）
- バトルコマンド選択から結果表示まで0.5秒以内
- アニメーションは60fps維持

### 3.3 UI/UX要件

- フォントは日本語対応（ゴシック体推奨）
- メッセージウィンドウはドラクエ風（ウィンドウ枠+テキスト送り）
- テキスト送りは「クリック」または「Enterキー」
- カラーパレットは深海をイメージした青・紺・水色系
- めんだこのスプライト/アイコンをCSSまたはASCIIアートで表現

### 3.4 サウンド要件

- BGM: タイトル・フィールド・バトル・ボス戦・エンディング（計5曲）
- SE: コマンド選択・攻撃・回復・レベルアップ・ゲームオーバー
- 音量調整: オプション画面でBGM/SE個別に調整可能
- ミュートボタンをゲーム画面に常時表示
