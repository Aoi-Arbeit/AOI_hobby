### 3.6 各関数の詳細仕様

#### `getRandomHand()`

```
目的    : コンピューターの手をランダムに決定する
引数    : なし
戻り値  : 0, 1, 2 のいずれかの整数（グー, チョキ, パーに対応）
処理    : Math.random() で 0〜1 の乱数を生成し、3 倍して小数切り捨て
```

```js
const getRandomHand = () => Math.floor(Math.random() * 3);
```

---

#### `judge(userChoice, cpuChoice)`

```
目的    : ユーザーとコンピューターの手から勝敗を判定する
引数    : userChoice {number} ユーザーの手（0〜2）
          cpuChoice  {number} コンピューターの手（0〜2）
戻り値  : 'win' | 'lose' | 'draw'
```

判定ロジック：`(userChoice - cpuChoice + 3) % 3` の計算結果で判定する。

| 計算結果 | 意味 | 戻り値 |
|----------|------|--------|
| `0` | 同じ手 | `'draw'` |
| `1` | ユーザー勝ち | `'win'` |
| `2` | ユーザー負け | `'lose'` |

```js
const judge = (userChoice, cpuChoice) => {
  const diff = (userChoice - cpuChoice + 3) % 3;
  if (diff === 0) return 'draw';
  if (diff === 1) return 'win';
  return 'lose';
};
```

---

#### `updateScore(result)`

```
目的    : 勝敗結果に応じてスコア変数を +1 し、画面のカウント表示を更新する
引数    : result {string} 'win' | 'lose' | 'draw'
戻り値  : なし
副作用  : winCount / loseCount / drawCount を更新
          #win-count / #lose-count / #draw-count の textContent を更新
```

```js
const updateScore = (result) => {
  if (result === 'win')       winCount++;
  else if (result === 'lose') loseCount++;
  else                        drawCount++;

  elWinCount.textContent  = winCount;
  elLoseCount.textContent = loseCount;
  elDrawCount.textContent = drawCount;
};
```

---

#### `updateStreak(result)`

```
目的    : 連勝・連敗カウントを更新し、#streak-text の表示を切り替える
引数    : result {string} 'win' | 'lose' | 'draw'
戻り値  : なし
副作用  : winStreak / loseStreak を更新
          #streak-text の textContent と color を更新
```

| result | winStreak | loseStreak | 表示テキスト例 |
|--------|-----------|------------|---------------|
| `'win'` | +1 | 0 にリセット | `🔥 3連勝中！` |
| `'lose'` | 0 にリセット | +1 | `💦 2連敗中…` |
| `'draw'` | 0 にリセット | 0 にリセット | `➖ 引き分け` |

```js
const updateStreak = (result) => {
  if (result === 'win') {
    winStreak++;
    loseStreak = 0;
    elStreakText.textContent = `🔥 ${winStreak}連勝中！`;
    elStreakText.style.color = 'var(--color-win)';
  } else if (result === 'lose') {
    loseStreak++;
    winStreak = 0;
    elStreakText.textContent = `💦 ${loseStreak}連敗中…`;
    elStreakText.style.color = 'var(--color-lose)';
  } else {
    winStreak  = 0;
    loseStreak = 0;
    elStreakText.textContent = '➖ 引き分け';
    elStreakText.style.color = 'var(--color-draw)';
  }
};
```

#### `updateResult(result, userChoice, cpuChoice)`

```
目的    : 勝敗結果に応じたメッセージを組み立てて #result-text に表示する
引数    : result     {string} 'win' | 'lose' | 'draw'
          userChoice {number} ユーザーの手
          cpuChoice  {number} コンピューターの手
戻り値  : なし
副作用  : #result-text の textContent と color を更新
          アニメーションをリセットして再適用する（フェードイン効果）
```

| result | メッセージ例 | 文字色 |
|--------|-------------|--------|
| `'win'` | `あなたの勝ち！🎉` | `var(--color-win)` |
| `'lose'` | `あなたの負け…😢` | `var(--color-lose)` |
| `'draw'` | `引き分け！🤝` | `var(--color-draw)` |

```js
const updateResult = (result) => {
  const messages = {
    win:  'あなたの勝ち！🎉',
    lose: 'あなたの負け…😢',
    draw: '引き分け！🤝',
  };
  const colors = {
    win:  'var(--color-win)',
    lose: 'var(--color-lose)',
    draw: 'var(--color-draw)',
  };

  // アニメーションをリセット（一度クラスを外して再付与）
  elResultText.style.animation = 'none';
  elResultText.offsetHeight;   // リフロー強制（アニメーションリセットのため必要）
  elResultText.style.animation = '';

  elResultText.textContent = messages[result];
  elResultText.style.color = colors[result];
};
```

#### `highlightButton(choice)` / `clearHighlight()`

```
目的    : 選択したボタンに selected クラスを付与 / すべてのボタンから除去
引数    : choice {number} 選択した手の番号（0〜2）
戻り値  : なし
```

```js
const clearHighlight = () => {
  handButtons.forEach(btn => btn.classList.remove('selected'));
};

const highlightButton = (choice) => {
  clearHighlight();
  handButtons[choice].classList.add('selected');
};
```

---

#### `playGame(userChoice)`

```
目的    : じゃんけん 1 回分のすべての処理を順に呼び出すメイン関数
引数    : userChoice {number} ユーザーが選択した手（0〜2）
戻り値  : なし
処理順序:
  1. clearHighlight()
  2. highlightButton(userChoice)
  3. cpuChoice = getRandomHand()
  4. result = judge(userChoice, cpuChoice)
  5. updateHands(userChoice, cpuChoice)
  6. updateResult(result)
  7. updateScore(result)
  8. updateStreak(result)
```

```js
const playGame = (userChoice) => {
  const cpuChoice = getRandomHand();
  const result    = judge(userChoice, cpuChoice);

  clearHighlight();
  highlightButton(userChoice);
  updateHands(userChoice, cpuChoice);
  updateResult(result);
  updateScore(result);
  updateStreak(result);
};
```

---

#### `resetGame()`

```
目的    : 全変数を 0 に戻し、画面表示を初期状態にリセットする
引数    : なし
戻り値  : なし
副作用  : winCount / loseCount / drawCount / winStreak / loseStreak を 0 にリセット
          全 UI 要素の表示を初期値に戻す
```

```js
const resetGame = () => {
  // 変数リセット
  winCount = loseCount = drawCount = 0;
  winStreak = loseStreak = 0;

  // 表示リセット
  elWinCount.textContent  = 0;
  elLoseCount.textContent = 0;
  elDrawCount.textContent = 0;

  elStreakText.textContent = 'さあ、はじめよう！';
  elStreakText.style.color = 'var(--color-text)';

  elUserHand.textContent = '❓';
  elCpuHand.textContent  = '❓';

  elResultText.textContent = '手を選んでください';
  elResultText.style.color = 'var(--color-text)';

  clearHighlight();
};
```
