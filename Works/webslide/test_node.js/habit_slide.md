# 2. 肉体的健康 (Physical Health)
### 休養・食事・運動の最適化

---

# 休養① 早寝早起きの極意

早起きの失敗原因は「起きる時間」ばかり考えること。
**極意：いつ寝るか（逆算）を決める。**

| 項目 | 理想のタイミング |
| --- | --- |
| **就寝** | ゴール時間を固定（例: 23:00） |
| **入浴** | 寝る **90分前** (シャワーなら30分前) |
| **夕食** | 寝る **3時間前** (消化のため) |

> 早寝早起きは、気合ではなく **「段取りの習慣化」** です。

---

# 休養② 何もしない時間（戦略的空白）

脳は「感情に紐づいた記憶」を強く定着させる性質があります。

* **推奨**: 勉強後 **5分間の空白** または **一言まとめ**

### 習慣化の極意：バネの法則
* 急激な変化 ＝ 脳の拒絶（現状維持バイアス）
* **ルール**: バネに気づかれないくらい **「小さく始める」**

# ジョブ・クラフティングの技術

仕事を自分の手で「作り変える」3つのアプローチ。

1. **認知クラフティング**
   * 意味の捉え直し（例：事務作業 → 誰かの笑顔のため）
2. **作業クラフティング**
   * やり方の工夫。得意な人を頼る（相手の貢献意欲も満たす）。
3. **人間関係クラフティング**
   * 最後に一言「ありがとう」を添える。

> 問いかけ習慣：**「これ、どうやったらもっと楽しめる？」**
