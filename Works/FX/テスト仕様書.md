## 1. テスト概要

### 1.1 テスト目的

本テスト仕様書は、FX Practice App MVP の品質を検証するために実施するテストの範囲・方法・合否基準を定義する。

### 1.2 テスト範囲

| テスト区分 | 対象 | ツール |
|---|---|---|
| UT-1 ビジネスロジック単体テスト | calc_pnl / calc_margin / calc_slippage | pytest |
| UT-2 レートエンジン単体テスト | RateEngine tick / get_rates / get_history | pytest |
| IT-1 認証統合テスト | POST /auth/register, POST /auth/login | pytest + httpx |
| IT-2 口座管理統合テスト | GET /account, POST /account/reset | pytest + httpx |
| IT-3 レート取得統合テスト | GET /rates, GET /rates/{symbol}/history | pytest + httpx |
| IT-4 成行注文統合テスト | POST /orders (market) | pytest + httpx |
| IT-5 指値・逆指値注文統合テスト | POST /orders (limit/stop) | pytest + httpx |
| IT-6 OCO注文統合テスト | POST /orders (oco) + キャンセル連動 | pytest + httpx |
| IT-7 ポジション管理統合テスト | GET /positions, POST /positions/{id}/close | pytest + httpx |
| IT-8 統計集計統合テスト | GET /trades, GET /stats/summary | pytest + httpx |
| ST-1 フロントエンド型検査 | TypeScript コンパイル (tsc --noEmit) | tsc |
| ST-2 E2Eシナリオ | 登録→注文→決済→統計確認の一連フロー | pytest |

### 1.3 テスト合否基準

- **UT/IT**: すべてのテストケースが PASS であること
- **ST-1**: TypeScript コンパイルエラー 0 件
- **ST-2**: E2Eシナリオが正常完了すること

## 2. 単体テスト仕様 (UT)

### UT-1-01: calc_pnl — JPY建て BUY 利益

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_pnl(pos, exit_price)` |
| 前提条件 | USDJPY BUY, entry=150.00, lot=1.0, |
| 入力 | exit_price=151.00 |
| 期待値 | +10,000 JPY (差100pip × 1万通貨) |
| 合否基準 | 返り値が 10000.0 |

### UT-1-02: calc_pnl — JPY建て SELL 損失

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_pnl(pos, exit_price)` |
| 前提条件 | USDJPY SELL, entry=150.00, lot=1.0 |
| 入力 | exit_price=151.00 |
| 期待値 | -10,000 JPY |
| 合否基準 | 返り値が -10000.0 |

### UT-1-03: calc_pnl — USD建て BUY 利益

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_pnl(pos, exit_price)` |
| 前提条件 | EURUSD BUY, entry=1.0850, lot=1.0, USDJPY≈150 |
| 入力 | exit_price=1.0950 (100pip上昇) |
| 期待値 | 約 +150,000 JPY (0.01 × 10000 × 150) |
| 合否基準 | 返り値が 14,000〜16,000 の範囲（USDJPY変動を考慮した許容幅） |

### UT-1-04: calc_margin — JPY建て

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_margin(symbol, lot_size, leverage, price)` |
| 入力 | USDJPY, 0.1lot, 25倍, 150.00 |
| 期待値 | 150.00 × 1000 / 25 = 6,000 JPY |
| 合否基準 | 返り値が 6000.0 |

### UT-1-05: calc_margin — USD建て

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_margin(symbol, lot_size, leverage, price)` |
| 入力 | EURUSD, 0.1lot, 25倍, 1.085, USDJPY≈150 |
| 期待値 | 1.085 × 1000 × 150 / 25 ≈ 6,510 JPY |
| 合否基準 | 返り値が 6000〜7000 の範囲 |

### UT-1-06: calc_slippage — 範囲検証

| 項目 | 内容 |
|---|---|
| 対象関数 | `calc_slippage(symbol)` |
| 入力 | USDJPY (100回実行) |
| 期待値 | 0.0 以上 3.0 以下の float |
| 合否基準 | 全100回が範囲内 |

### UT-2-01: RateEngine — tick でレート変化

| 項目 | 内容 |
|---|---|
| 対象クラス | `RateEngine` |
| 手順 | 初期化後に tick() を10回実行 |
| 期待値 | bid < mid < ask、各通貨ペアのレートが存在する |
| 合否基準 | 全tick で bid < ask, spread == 設定値 |

### UT-2-02: RateEngine — get_history で300本のローソク足

| 項目 | 内容 |
|---|---|
| 対象クラス | `RateEngine` |
| 手順 | get_history("USDJPY", "1m") |
| 期待値 | 300本以上のOHLCリスト |
| 合否基準 | len(candles) >= 300, 各barにtime/open/high/low/close |
